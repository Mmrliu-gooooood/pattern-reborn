# 产品化实施路线

日期：2026-10-21。状态：本轮本地功能已接通；部署不在本轮范围。实际运行、操作与边界见 [Web 工作台](web-workspace.md) 和 [本地交付指南](local-release.md)。验证证据集中在根目录 `design-qa.md`；实施前审查和 `docs/superpowers/` 保留为历史资料。

## 1. 已完成：独立工作台与服务边界

React/Vite 通过回环 FastAPI 复用 Python 核心，实现上传/示例 → 提取与精修 → 分析 → 重组配色 → 可选远程生成 → 文创 → 导出。界面采用已确认的精修工坊视觉方向；原 Streamlit 全流程继续保留。

本地服务限制同源、请求体、坐标和路径；原图单独存储且不被结果覆盖。保存使用原有来源与确认流程，改变上游会标记后续依赖过期，旧成果和导出快照保留。

## 2. 已完成：本地个人创作功能

1. 项目管理：搜索、分类排序、重命名、复制、归档恢复、完整项目备份与独立项目回导；原图、已有成果与历史文件校验后导入。
2. 提取质量与修正：自动、OpenCV、取色/颜色容差、整图和可选本地 MobileSAM；有界清理、框选、笔触、柔化、透明度保护与明确提示。
3. 编辑恢复：提取与构图草稿自动保存、重开恢复、自动版本、命名方案、两份并排比较、恢复前备份；有效快照存在时恢复损坏的项目 JSON。
4. 重组配色：六种布局、画布参数、配色灵感与逐色编辑、撤销重做、预览保存和版本比较。
5. 成果交付：当前或历史作品、PNG/可选 SVG/来源 ZIP、文创预览和导出记录；完整项目备份与程序源码包用途明确区分。
6. 生成服务：Seedream/Qwen/OpenRouter/自定义图像 API、本机持久设置与 Windows 加密密钥、公开图像模型目录、逐次远程付费同意、异步任务状态、取消、重复请求防护与失败恢复入口；付费测试使用模拟请求。

顶层 schema version 1 保持不变。Web 元数据和 `.web-workspace/` 草稿/快照 sidecar 承载新增功能；没有通过修改版本号伪装迁移。损坏记录恢复校验引用文件；不承诺恢复已经丢失的图像。

## 3. 已完成：本地源码发行工具

- `.venv` 安装与环境检查仅支持 Python 3.11 x64，首次依赖安装通常需要网络；离线安装要求完整兼容 wheelhouse。
- 源码 ZIP 含已构建网页、版本、SHA-256 manifest、依赖版本、第三方许可文本及使用说明；不含个人项目、模型、密钥或虚拟环境。
- 提供启动入口、脱敏诊断、新目录升级、旧目录保留与回退/卸载说明。
- 已在本机验证打包完整性、隔离目录启动和升级保留数据；隔离启动使用已有 Python 依赖，没有宣称全新 Windows 系统安装验证完成。

源码包需要 Python 与依赖，不是独立 EXE。项目自身 LICENSE 仍待权利人明确，不能把本地打包完成等同于已获公开再分发授权。

## 4. 后续验收与质量工作

- 在全新受支持 Windows 环境验证联网/离线依赖安装、启动、升级和回退，记录环境差异。
- 扩充真实剪纸、织物与器物照片样本，记录人工质量评价、细线/镂空保留和耗时；合成样本回归不代表任意实拍质量。
- 继续浏览器任务、桌面尺寸、键盘与无障碍检查，保持界面行为、文件完整性和恢复测试。
- 如需验收真实生成，另获明确授权并限定费用；本轮没有真实付费调用。取消不能保证供应商中止或退款；任务和去重记录目前不跨服务重启保留。
- 当前为一个进程操作一个工作区，跨进程互斥、大规模项目库与磁盘清理可按实际需求继续完善。

## 5. 后续阶段：向其他人提供使用

本轮未发布线上站点。GitHub 源码/发行包分发与在线可用服务是不同交付物；静态托管不能独立承载当前 Python 处理与持久存储。

部署前单独确定用户隔离、持久存储、任务执行、上传限额、超时、并发、存储清理、密钥、配额和费用控制，再评估 Vercel 或其他宿主。验收应由另一台设备的独立用户完成完整创作，验证项目不串用、服务重启不丢失承诺保存的数据、公网无法访问开发者目录与私密配置。此阶段需要新的部署授权。

未跟踪的 `p1-review.patch` 不属于本轮改动，不修改或打入程序发行包。
