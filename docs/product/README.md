## 当前状态与文档优先级

产品定位为可长期使用的本地个人纹样创作工作台。本轮已接通 React/Vite + 本地 FastAPI 的项目管理、编辑恢复、重组配色、生成服务、文创与导出功能，并提供本地源码发行、安装、升级和诊断脚本。Python 处理核心、schema version 1 和 Streamlit 全流程保留。

## 产品目标与已实现范围

面向反复整理、提取、调整和应用传统纹样的个人创作者，支持找到项目 → 继续编辑 → 比较方案 → 保存并重新打开 → 导出交付。提取质量通过代表性素材和人工评价衡量，不把算法成功返回等同于结果可用。

| 领域 | 当前本地实现 | 实际边界 |
| --- | --- | --- |
| 项目 | 搜索分类排序、上传与示例、重命名、归档恢复、复制、完整项目备份与回导 | 导入生成独立项目；没有多用户隔离或云同步 |
| 提取 | 自动、OpenCV、选色、保留整图、可选 MobileSAM；框选、缩放平移、保留/擦除、撤销重做、蒙版比较、柔化 | 原透明度不可扩大；复杂背景、细线、镂空仍需人工检查 |
| 编辑恢复 | 提取/构图草稿自动保存，浏览器与磁盘副本，重开恢复；自动与命名版本、两份并排比较、恢复前备份 | 过期草稿不能直接覆盖新成果；损坏记录恢复依赖有效历史与完整图像 |
| 重组配色 | 六种布局、画布参数、主色与配色灵感、逐色编辑、撤销重做、保存和版本比较 | 数字创作工具，不作历史颜料鉴定或专业矢量节点编辑 |
| 分析与文创 | 主色/结构分析，已有模板上的本地文创预览，提取/重组/生成作品来源标记 | 场景预览不等于真实生产工艺验证 |
| 远程生成 | Seedream/Qwen 配置、会话密钥、逐次付费同意、任务状态、取消与重复请求防护、失败信息和重试入口 | 验证使用模拟供应商；已发送请求可能继续计费；任务状态不跨服务重启保留 |

## 交互与视觉原则

- 以项目库和工作台承载创作；草稿自动保存、保存作品、命名方案与完整备份表达不同操作。
- 作品优先：紧凑导航、中央大画布、右侧属性、可见保存状态；包含空白、载入、失败、缺依赖、过期草稿和冲突状态。
- 保留已确认方向：等尺寸项目网格、墨绿导航、象牙白内容、淡青素材栏、金色植物装饰与朱砂红「纹」印章。
- 框选与笔触直接在画布上操作；重组与配色可撤销重做；两份保存版本可并排比较。
- 桌面优先，检查 1440×900、1280×720；窄窗口支持必要操作，完整移动端编辑另评估。

## 架构与发布边界

前端通过同源回环 API 使用 Python 服务，核心图像、领域模型、来源追踪和原子写入继续独立于界面。Web 元数据在 `processing_parameters.web_workspace`；草稿、版本与损坏记录副本位于每个项目的 `.web-workspace/`，没有更改顶层 schema version 1。

本地版默认单人，数据保存在本机；安装依赖后核心创作离线运行。远程生图仅在用户逐次确认后发送参考图和描述。会话密钥不写项目、浏览器存储或备份；取消只保证不发布该结果，不能撤回供应商已经接收的请求。任务与会话设置在服务内存中，重启清除；已保存的作品保留。

当前锁与 revision 检查保护一个 Web 进程，不能协调另一个 Web/Streamlit 进程同时写入同一工作区。在线版需要另行设计用户隔离、持久存储、任务执行、密钥和配额，不能直接公开本地目录。

本轮没有部署线上站点或发布到 GitHub/Vercel。静态前端本身不包含当前 Python 后端与持久存储。程序源码 ZIP 需要 Python 及依赖；第三方声明不等于项目自身授权，公开再分发前仍需权利人明确项目许可证。

## 继续保留的约束

原图不可被结果覆盖；路径校验、资源上限、原子写入和密钥保护继续有效。来源、授权、第三方组件与 AI 参与如实标注。恢复和升级先保留可回退状态；无有效副本时不能承诺重建遗失文件。账号、团队协作、计费平台、社区、训练和专业矢量编辑器不属于本轮本地范围。验证证据与剩余问题见根目录 `design-qa.md`。
