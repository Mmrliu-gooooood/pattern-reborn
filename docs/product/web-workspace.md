# 本地创作工作台

2026-10-21：独立 React/Vite 工作台通过本地 FastAPI 复用 Python 核心，现已覆盖项目管理、提取与分析、编辑恢复、重组配色、生成服务、文创预览及导出。原 Streamlit 全流程保留。这里描述实际本地功能；安装、发行、升级和排障见 [本地使用指南](local-release.md)。

## 安装与运行

需要 Windows x64、Python 3.11 和 PowerShell。程序源码 ZIP 已含 `web/dist/client`，不需要 Node 才能使用：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-local.ps1
powershell -ExecutionPolicy Bypass -File scripts\start-local.ps1
```

安装后也可双击 `Start-Workspace.cmd`，浏览器打开 `http://127.0.0.1:8510`。程序源码 ZIP 不是独立 EXE；首次安装通常联网取得 Python 依赖，之后核心创作可离线。可选 MobileSAM 权重不随包下载。

从 Git 源码开发时，先用 `scripts/bootstrap.ps1` 创建 `.venv`，安装 Web 依赖，再构建网页：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev,web]"
cd web
npm ci
cd ..
.\scripts\run-web.ps1 -Build
```

构建需要 Node 22.12+ 或兼容的新版本及项目内依赖，不要求全局安装这些包。Node 不在 PATH 时传 `-NodeExecutable "完整路径\node.exe"`。已有构建可直接运行 `scripts/run-web.ps1`。开发模式可在 `web` 运行 `npm run dev`，Vite 将 `/api` 转发到 8510。一个工作区仅用一个服务进程写入，避免另开 Streamlit 同时修改。

## 项目库、备份与恢复

项目库提供等尺寸真实封面、搜索、分类排序、上传新建、重命名、复制、归档和恢复。六份自带参考素材按仓库来源与授权展示，打开后才创建本地项目，不将传统参考自动称作已核实非遗。

「完整项目备份」包含原图、项目记录、已有成果、磁盘草稿、历史快照和导出文件；历史引用的文件缺失时会明确拒绝备份。项目库的「导入备份」先检查 ZIP 路径、规模、清单和哈希，再生成独立项目，不覆盖原项目。包含原图且清单有效的旧作品包也可转换导入；作品交付包仍不能代替完整历史备份。程序源码 ZIP 用于安装应用，与项目备份 ZIP 不可互换。

设置中的「项目恢复检查」可发现打不开但存在有效历史的项目。恢复会校验历史引用与图像，另外保留损坏记录的脱敏副本；没有完整原图或成果时不能重建遗失数据。完整机器备份与安全升级操作见 [本地指南](local-release.md)。

## 提取与精修

- 框选、保留/擦除笔刷、画笔尺寸、缩放平移、自适应、撤销重做、原图/蒙版/结果比较和边缘柔化。
- 自动：透明素材保留源透明度；鲜明单色前景尝试按色相识别，其他情况使用 OpenCV。
- OpenCV：按素材档案使用明暗、颜色或框选辅助；器物照片配置需要先框选主体。
- 选色：输入颜色或在工作图取色，调节 Lab 容差；背景同色时需要手工擦除。
- 保留整图：直接使用整张图片，保留原有半透明像素和细小区域。
- MobileSAM：本机具备依赖与校验通过的权重时可选，先框选主体；不自动安装或下载，缺少时其他本地模式照常工作。

小区域过滤、填孔和平滑可选，先于手动画笔执行。填孔会封闭镂空，平滑可能损失细线，默认关闭。分析使用二值蒙版；柔化只改变 RGBA 边缘，结果 alpha 不超过源 alpha。RGB 和原图字节不被覆盖。复杂背景、细线、同色区域需要人工目视判断，不宣称一键完美分割。

坐标按方向已校正、最长边 2048 的工作图记录。一次最多 100 条笔触，每条 3000 点，总计 20000 点。图片上传限 24 MB；项目 ZIP 导入限 256 MB，解包另有文件数、总量与像素预算。

## 草稿、历史与方案比较

提取及构图编辑保留浏览器副本，并在编辑稳定后自动同步到项目磁盘。重开时可恢复或丢弃草稿；项目版本已经变化的草稿会提示过期，不能直接覆盖新成果。草稿保存只记录编辑参数，不等于已发布提取/构图作品，导出前仍需保存。

保存产生自动版本；「版本」可给当前已保存状态命名，勾选两份并排比较。恢复历史前会先保留当前已保存状态。未保存的页面修改需自行决定保留或丢弃。恢复前后原图相同，旧成果和导出记录依赖各自的历史引用，不因新提取而删除。

## 重组、配色与导出

- 六种布局：二方连续、四方连续、镜像、旋转、放射、边框。支持 64–4096 px 画布、比例、间距、角度与随机种子；极端组合仍受核心中间图像预算限制。
- 最多六组提取主色、三组配色灵感和逐色替换，保留局部明暗与 alpha；构图和配色均支持撤销重做、草稿及版本保存。
- `web_design.py` 复用布局核心，裁去透明空边并按画布归一化纹样尺寸；预览最大 1200 px，保存与导出按设定尺寸渲染。数字配色不宣称复原历史颜料。
- PNG 导出提取或重组作品；SVG 按需调用本地 VTracer，缺少时禁用、失败时保留 PNG。SVG 是轮廓描摹，可能简化照片纹理。
- 作品 ZIP 包含对应图像、来源归因报告和 `workspace-settings.json`，可选择附原图。完整项目备份另外提供。
- 导出位于 `outputs/<project-id>/<export-id>/`，记录对应作品快照。再次提取使当前重组过期，但历史快照仍可下载；没有自动清理磁盘。

## 生成、分析与文创

「灵感与应用」可查看主色/结构分析，将已保存重组或 AI 生成作品用于本地文创模板，保存预览并导出 PNG 或来源包。AI 辅助标记和来源随作品保留。

服务设置提供 Seedream/Qwen、HTTPS 服务地址、模型和会话 API Key；也可读取本机环境配置密钥。会话密钥不回显、不进浏览器存储、项目或备份；服务重启后会话设置失效。

每次生成需要明确同意发送参考图和描述并承担可能费用。后台任务报告等待、运行、成功、失败、取消与输入已变化等状态，同一会话的相同请求 ID 不重复提交；不会自动切换供应商。取消保证丢弃该任务结果，已发送的远程请求仍可能继续执行和计费。任务状态和去重记录存在服务内存中，重启清除；已保存生成文件仍在项目内。重新提交可能是新的付费请求，需要再次确认。本轮验证采用模拟供应商，未发送真实付费请求。

## 数据与本地边界

- `web_api.py` 只监听回环地址，限制同源、路径和请求；读取设置或启动服务不会触发供应商调用。
- schema version 1 保持不变。元数据在 `processing_parameters.web_workspace`，草稿、快照和恢复副本在项目 `.web-workspace/`。
- 保存提取沿用确认与后续过期规则；上游改动保留旧成果。预览和保存使用相同处理路径。
- 进程内锁和 revision 校验不提供与另一个 Web/Streamlit 进程同时写入的跨进程互斥。
- 本轮未部署；静态网页单独上传不能替代 Python 服务、持久存储和多用户隔离。
- 已有环境检查与隔离目录启动验证不等于全新 Windows 依赖安装；具体证据及剩余问题见根目录 `design-qa.md`。
