# 本地工作台使用手册

## 开始创作

从项目库「新建项目」导入图像，或打开自带的真实工艺参考素材。原始文件会单独保留，不会被编辑覆盖。项目菜单支持重命名、复制、完整备份和归档；归档项目可恢复。

## 提取纹样

先框选要保留的纹样，使用保留／去除笔刷修正，再预览并保存。Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做，Ctrl+S 保存。

「提取设置」提供：
- 智能本地提取：已有透明度的素材优先保留透明边缘；色彩明显的图案优先使用色彩分离，其他图像使用轮廓提取。
- 按颜色提取：选取目标颜色，调整容差；适合纯色剪纸等场景。
- 经典轮廓提取：按素材类型使用原有 OpenCV 流程。
- 保留整张图像：适合已抠好或希望完整使用的图像。
- 本机已有 MobileSAM 依赖和权重时，可选精细提取；不会自动下载模型。

去杂点、填孔用于清理蒙版；剪纸的镂空通常不应填满。画笔修改在自动清理后生效。提取质量与拍摄背景有关，请检查细线、镂空和半透明边缘，复杂照片仍需人工修正。

## 草稿与版本

修改后约 0.8 秒自动保存草稿，状态显示在画布上方。浏览器副本会立即保存，服务可用时同步到项目目录。草稿不等于正式作品：导出与后续流程使用点击「保存」产生的结果。

重新打开时可以恢复或丢弃草稿。若项目已被其他窗口改动，旧草稿会标为过期；不要用过期草稿覆盖新版本。

右上角「版本」能查看自动记录，给当前已保存结果命名、选择两份方案并排比较，或恢复历史版本。恢复前会再保留当前已保存状态。重组、配色也支持撤销／重做。

## 重组与配色

保存提取后进入「重组与配色」。六种构图包括二方／四方连续、镜像、旋转、放射、边框。设置画布尺寸、纹样大小、间距、角度，再更新预览。画布支持 64–4096 px；过大的中间单元仍受内存预算限制，超限会提示调整。

配色可选预设或逐个更换主色，保留纹理明暗和透明度；可设置透明或实色背景。保存作品后，可在版本窗口命名方案或返回历史版本继续创作。

## 灵感与应用

「文创预览」将已保存的重组或 AI 生成作品放入书签、包装等本地模板。左侧选择作品，选择应用模板并生成，结果会保存并可下载。

「生成灵感」需要先在「服务设置」配置所选服务。界面会展示当前模型和支持的尺寸。输入创作描述、结构保留程度与用途，明确勾选本次发送参考图、提示词及承担费用，才会提交。支持任务状态、手动重试和取消；已发送的远程请求可能无法撤回且可能计费。取消后不发布结果，输入已改变时也不会用旧任务覆盖当前项目。

同一请求不会重复提交，同一项目同时只允许一个生成任务。服务重启会清空会话密钥和临时任务状态；已保存的生成作品及其来源保留。中断后先检查作品列表，再决定是否重新提交，避免重复收费。

API Key 仅保存在当前服务进程对应的浏览器会话中，不写入项目、草稿、备份或浏览器存储。也可由本地环境配置服务密钥；不要把密钥填在作品名称或提示词中。可随时清除会话密钥。

「查看纹样分析」显示主色等分析数据，仅用于数字创作参考，不代表历史颜料鉴定。

## 导出、备份与恢复

- PNG：保存当前提取或重组图像，透明背景会保留。
- SVG：本机有 VTracer 时按需描摹矢量轮廓；照片和织物纹理可能被简化，建议同时保留 PNG。
- 作品包 ZIP：用于交付图像、参数与来源记录。可选择包括原始素材；含原始素材的新版来源包可导入为独立项目，但它只包含选定交付成果，不等同于完整备份。
- 完整项目备份：从项目菜单或版本窗口下载。包含原始素材、草稿、历史版本及导出快照，适合迁移和恢复。项目库「导入备份」校验后创建独立项目，不覆盖已有项目。备份上限为 256 MB 压缩、512 MB 展开；超限应保留原项目目录并按使用说明做文件级备份。

历史导出保留当时版本的文件；重新提取会使当前重组失效，但不会改写历史下载。项目记录损坏或丢失时，可在设置里的「项目恢复检查」选择有效历史版本；原损坏内容会另外保留。如果图像文件也丢失，应从完整备份恢复。

## 安装与维护

运行发行包中的 scripts/install-local.ps1 安装到项目自己的 .venv，再双击 Start-Workspace.cmd。首次安装需要 Python 3.11 x64 和下载依赖；已有完整依赖时，基础创作可以离线使用。发行包是本地源码运行包，并非免安装 EXE。

使用 diagnose-local.ps1 检查 Python、依赖、本地服务与可选能力。升级使用 upgrade-local.ps1，生成新的并排目录，保留旧程序和数据；升级失败时继续使用旧目录。具体参数见随包的 docs/product/local-release.md。

默认项目在 workspace/，导出在 outputs/。不要同时用旧 Streamlit 和新版工作台修改同一个项目。定期备份，不要只保留浏览器缓存。当前版本仅监听本机，没有部署到公网。
